# CineCore

CineCore is a modern WordPress-based movie and TV series management platform.

## Features

- Movie management
- TV series management
- Season and episode management
- TMDB integration
- Automatic movie and TV metadata
- Poster and backdrop management
- Download links
- Streaming servers
- Subtitle management
- Movie and TV search
- Advanced filtering
- Responsive cinematic frontend
- SEO support
- Telegram integration
- Admin content management

## Project Structure

- `cinecore-plugin/` — Core CineCore functionality
- `cinecore-theme/` — CineCore frontend theme

## Requirements

- WordPress
- PHP 8+
- MySQL
- Node.js and npm for frontend development
